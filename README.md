## ✨ درباره پروژه

**پارسا آفیس** یک سامانه‌ی کامل اتوماسیون اداری است که با Django و طراحی مدرن ساخته شده. این پروژه از یک اپلیکیشن ساده Todo شروع شد و به یک پلتفرم جامع برای مدیریت وظایف، ارتباطات سازمانی و پروفایل کاربران تبدیل شد.

### 🎯 چه چیزی رو حل می‌کنه؟

- 📋 مدیریت وظایف تیمی با تخته کانبان
- 💬 چت سازمانی با پشتیبانی از فایل، عکس، ویدیو و صدا
- 👥 پروفایل کاربران با اطلاعات سازمانی (داخلی، ایمیل سازمانی)
- 🔔 نوتیفیکیشن پیام‌های جدید
- 🌓 حالت روشن/تاریک

---

## 🚀 ویژگی‌های کلیدی

### 📊 داشبورد و مدیریت وظایف
- تخته کانبان با **Drag & Drop** برای جابه‌جایی وظایف
- فیلتر خودکار بر اساس وضعیت (در انتظار، در حال انجام، انجام شده)
- اولویت‌بندی سه‌سطحی (پایین، متوسط، بالا)
- مودال مشاهده جزئیات کامل وظیفه
- آمار زنده در بالای داشبورد

### 💬 چت سازمانی
- گفتگوی خصوصی بین کاربران
- پشتیبانی از **متن، عکس، ویدیو، صدا و فایل**
- نشانگر پیام‌های خوانده‌نشده
- بروزرسانی خودکار پیام‌ها
- نوتیفیکیشن Toast برای پیام‌های جدید
- پیش‌نمایش قبل از ارسال فایل

### 👤 پروفایل و کاربران
- کارت پروفایل با کاور گرادیانت
- اطلاعات سازمانی (شماره داخلی، ایمیل سازمانی)
- کپی سریع هر فیلد
- جستجوی زنده در لیست کاربران
- شروع گفتگو مستقیم از پروفایل

### 🎨 طراحی و تجربه کاربری
- **Design System** کامل با CSS Variables
- حالت روشن/تاریک با ذخیره‌سازی
- فونت فارسی Vazirmatn
- کاملاً **RTL** و ریسپانسیو
- انیمیشن‌های نرم و میکرواینترکشن‌ها
